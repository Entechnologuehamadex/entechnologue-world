# Entechnologue World

Placeholder site for **Entechnologue World** — the parent brand behind Sheda, Dr Food Ltd and future ventures.

> We are on the path to shape the landscape with innovative technologies.

Live at [entechnologue.org](https://entechnologue.org).

## Structure

- `index.html` — the whole page (inline CSS, no build step)
- `assets/` — background, logo, favicons and social preview image

To preview locally, open `index.html` in a browser. To deploy, import the repo into Vercel as a static site (no framework, no build command).
